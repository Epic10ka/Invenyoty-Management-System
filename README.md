## About

This project was developed to practice my coding skills, logic and knowledge of POO in Python and my first time using SQL to save data.


## Concepts Applied

* Object-Oriented-Programming (OOP)
* Modularization
* Exception handling
* File saving (SQL Data Base)
* Input validation
* Loops and functions
* Menu-Driven Interface
* Data encapsulation


## Features

* Interactive menu interface
* Register items
* Edit registered items
* Edit items name, batch and status
* Automatic data saving (sqlite3)
* Multi-language support


## Built with
- Python 3
- Rich
- sqlite3
- Standard Library (pathlib, time, os, uuid)
